# نظام الإتقان (Al-Itqan) — إدارة الحلقات القرآنية

منصة ويب متكاملة باللغة العربية (**RTL**) لإدارة حلقات تحفيظ القرآن الكريم، تسجيل الحضور والتسميع بأسبقية الحضور وترتيب الأدوار، متابعة الورد اليومية، واستخراج التقارير الشهرية الجاهزة للمشاركة عبر الواتساب والطباعة.

---

## ✨ المميزات الرئيسية (Features)

### 1. لوحة التحكم (`/`)

- عرض إحصائيات فورية لإجمالي الحلقات، إجمالي الطالبات المسجلات، وحلقات اليوم المجدولة حسب يوم الأسبوع الحالي.
- اختصارات سريعة للوصول إلى تسجيل الحضور، متابعة الورد، إضافة الطالبات، والتقارير الشهرية.

### 2. إدارة الحلقات (`/circles`)

- إضافة، تعديل، وحذف الحلقات ببيانات **اسم المعلمة**، **أيام الانعقاد**، **ساعة وتوقيت الحلقة**، والملاحظات.
- عرض عدد الطالبات المقيدات في كل حلقة تلقائياً عبر MongoDB Aggregation.
- نافذة تأكيد حذف مخصصة (`ConfirmDialog`) للحماية من الحذف العرضي.

### 3. إدارة الطالبات (`/students`)

- تسجيل الطالبات وربطهن بالحلقة المناسبة عبر قائمة منسدلة مخصصة (`CustomSelect`).
- البحث الفوري بالاسم أو رقم الهاتف والتصفية حسب الحلقة، مع رابط تواصل مباشر عبر واتساب.
- تبديل علامة **التحذير بالحذف (`⚠️`)** مباشرة من جدول الطالبات، مع أزرار أيقونات مخصصة للتعديل والحذف.

### 4. تسجيل الحضور والتسميع وحجز الأدوار (`/attendance`)

- شريط أسبوعي تفاعلي لعرض جلسات الأسبوع الحالي والانتقال بينها بسهولة.
- تسجيل حالات الطالبات (**حاضرة**، **غائبة**، **معتذرة**، **لم يُسجّل**) مع **حفظ تلقائي (Auto-Save)** في قاعدة البيانات.
- **إدارة الأدوار الذكية**:
  - تخصيص رقم الدور تلقائياً حسب أسبقية الحضور.
  - حقل رقمي قابل للتعديل المباشر مع أزرار تقديم/تأخير سريعة (`▲` / `▼`) و**ترحيل تلقائي** لباقي القائمة عند تعديل أي دور أو عند تحويل طالبة من حاضرة إلى غائبة/معتذرة لسد الفجوات ومنع التكرار.
- متابعة حالة التسميع لكل طالبة حاضرة.
- ربط تلقائي مع **الإجازات الرسمية** المسجلة في الإعدادات (تعطيل التسجيل في يوم الإجازة دون احتساب غياب، مع إمكانية التبديل اليدوي).
- توليد **قائمة الحضور والغياب وحجز الأدوار للواتساب** منسقة مع علامات التسميع (`✅`) وخانات الأدوار الفارغة المرقمة للحجز، بالإضافة إلى كشف طباعة `A4`.

### 5. متابعة الورد اليومية (`/homework`)

- متابعة الورد والورداليومي وفق التقويم الشهري الفعلي (من السبت إلى الخميس مع استبعاد الجمعة).
- مستقلة تماماً عن إجازات الحلقات بحيث يستمر تسجيل الورداليومي بانتظام.
- حساب نسبة الإنجاز الأسبوعي لكل طالبة وطباعة كشف الورد الأسبوعي.
- نافذة تقرير الوردوالحضور الشهري للواتساب مع إمكانية التعديل والنسخ بضغطة زر.

### 6. التقارير الشهرية الشاملة (`/reports`)

- محرك تقارير نقي (`buildReport` & `renderReportText`) يقسم الشهر إلى أسابيع تقويمية منضبطة بتوقيت `UTC`.
- استبعاد جلسات الإجازات تلقائياً من التقرير الشهري دون إظهارها أو احتسابها غياباً.
- احتساب الأوسمة الأسبوعية للأسابيع المكتملة فقط:
  - `🏆`: إتمام جميع واجبات الأسبوع.
  - `🏅`: إتمام جميع واجبات الأسبوع + حضور جميع حصص الحلقة في الأسبوع.
- عرض جدول متابعة تفصيلي واسع لكل طالبة مع نص تقرير الواتساب القابل للتعديل والنسخ ونسخة مخصصة للطباعة.

### 7. الإعدادات والإجازات الرسمية (`SettingsModal`)

- تخصيص اسم المشرفة، ومقدمة وخاتمة رسائل الواتساب.
- إضافة وحذف الإجازات الرسمية (إجازة عامة لجميع الحلقات أو إجازة خاصة بحلقة محددة ضمن نطاق تاريخي)، مع مزامنة تلقائية لجلسات الحضور في نفس الفترة.

### 8. تجربة المستخدم والواجهة (UI/UX)

- واجهة **RTL** عربية بالكامل مع خط `Baloo Bhaijaan 2` وألوان هادئة متناسقة مع هوية الإتقان.
- قائمة جانبية ثابتة (`Fixed / Sticky`) على الشاشات الكبيرة مع قائمة منزلقة (`Drawer`) للهواتف.
- شريط تمرير مخصص (`Custom Scrollbar`)، مؤشرات تحميل موحدة (`Spinner` / `LoadingState`)، نوافذ منبثقة بحركة فتح وإغلاق سلسة، والتحقق من المدخلات عبر `React Hook Form` + `Zod` وإشعارات `React Toastify`.

## 🛠️ التقنيات المستخدمة (Tech Stack)

### Frontend (`/frontend`)

- **Framework**: Next.js `16.4.6` (App Router) & React `19.3.0`
- **Language**: TypeScript `^5`
- **Styling**: Tailwind CSS `4.3.3` + Custom CSS Animations & Theme Scrollbar
- **Data Fetching & Caching**: `@tanstack/react-query` `^5.108.3`
- **Forms & Validation**: `react-hook-form` `^7.53.0` + `@hookform/resolvers` `^3.9.0` + `zod` `^3.23.8`
- **Icons & Notifications**: `react-icons` `^5.7.0` + `react-toastify` `^10.0.6`

### Backend (`/backend`)

- **Runtime & Framework**: Node.js + Express `^4.21.2`
- **Language**: TypeScript `^5.7.3` + `tsx` `^4.19.2`
- **Database & ODM**: MongoDB Atlas + Mongoose `^8.9.5`
- **Validation**: `zod` `^4.6.7` + Validation Middleware
- **Testing**: Node.js native test runner (`tsx --test`) — 17 اختباراً تغطي منطق بناء التقارير الشهرية وتوليد نصوص الواتساب
- **Deployment Ready**: مهيأ للتشغيل المحلي أو على **Vercel Serverless Functions** (`@vercel/node`, `vercel.json`)

## 🔌 نقاط النهاية (API Endpoints)

| المسار                      | الوصف                                                                           |
| --------------------------- | ------------------------------------------------------------------------------- |
| `GET /api/health`           | فحص حالة السيرفر والاتصال بقاعدة البيانات                                       |
| `/api/circles`              | إدارة الحلقات (`GET`, `POST`, `PUT`, `DELETE`)                                  |
| `/api/students`             | إدارة الطالبات (`GET`, `POST`, `PUT`, `DELETE`) مع التصفية والبحث والحذف الناعم |
| `/api/attendance`           | جلب وحفظ جلسات الحضور والأدوار والتسميع مع كشف الإجازات الرسمية تلقائياً        |
| `/api/homework`             | جلب وتسجيل حالة الورداليومي للطالبات                                            |
| `GET /api/reports/homework` | توليد بيانات التقرير الشهري ونص رسالة الواتساب الجاهزة                          |
| `GET /api/reports/monthly`  | توليد إحصائيات التقرير الشهري للعرض الجدولي والطباعة                            |
| `/api/holidays`             | إدارة الإجازات الرسمية ومزامنتها مع جلسات الحضور                                |
| `/api/settings`             | جلب وتحديث إعدادات المشرفة ونصوص الواتساب                                       |

## 🚀 التشغيل والاختبار محلياً (Getting Started)

### 1. إعداد وتشغيل الباك إند (`backend`)

```bash
cd backend
npm install
# أنشئ ملف .env بالاعتماد على .env.example وأضف PORT و MONGO_URI
npm run dev
```

- يعمل السيرفر افتراضياً على: `http://localhost:5000`
- لتشغيل اختبارات الباك إند والتحقق من الأنواع:
  ```bash
  npm test
  npx tsc --noEmit
  ```

### 2. إعداد وتشغيل الفرونت إند (`frontend`)

```bash
cd frontend
npm install
# اختياري: أضف NEXT_PUBLIC_API_URL في .env.local (الافتراضي http://localhost:5000/api)
npm run dev
```

- يعمل التطبيق على: `http://localhost:3000`
- لبناء نسخة الإنتاج:
  ```bash
  npm run build
  ```
